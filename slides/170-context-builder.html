SO HERE'S THE REAL SKILL.

YOU'RE NOT A
PROMPT WRITER.
YOU'RE A CONTEXT BUILDER.

The model brings broad knowledge. The prompt starts the task. Context tells it which version of the task you actually mean.

  • The model — lots of learned patterns, but no access to your situation.
  • The prompt — the question you type; useful, but usually too small.
  • The context — who it’s for, why it matters, what constraints apply, what “good” looks like.
